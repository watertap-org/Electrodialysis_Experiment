Demo Workflow Documentation
===========================

This section explains the standalone process demo scripts in
``scripts/demos/``:

- ``demo_ossp_proc.py`` for one-stage single-pass electrodialysis, and
- ``demo_oscr_proc.py`` for one-stage concentrate-recycle electrodialysis, and
- ``demo_kssp_proc_k2.py`` for two-stage single-pass electrodialysis.
- ``demo_kscr_proc_k2.py`` for two-stage concentrate-recycle electrodialysis.

The goal is to help users understand not only how to run these scripts, but
also what process assumptions they encode and how they connect to the
process-model core under ``src/electrodialysis_experiment/processes``.
