# Repository Structure

This repository combines two main workstreams:

- Python package code for electrodialysis process modeling.
- Script-level workflows for training, inference, and analysis.

## Top-level layout

- `src/electrodialysis_experiment/`: package source code.
- `scripts/`: runnable driver scripts for simulations, training, LOOCV, and analysis.
- `tests/`: automated tests.
- `docs/`: project documentation.

## Important subareas

- `src/electrodialysis_experiment/processes/`
  Contains flowsheet definitions such as one-stage and k-stage single-pass processes.

- `src/electrodialysis_experiment/configs/`
  Holds YAML configuration files for process structure, initialization, scaling,
  and solver behavior.

- `src/electrodialysis_experiment/data/`
  Stores raw inputs plus derived and output artifacts generated by training,
  inference, and cross-validation workflows.

- `scripts/`
  Includes direct runners for single-process simulations (`run_proc_ossp.py`,
  `run_proc_tssp.py`), model training, inference, and leave-one-out validation.

## Practical navigation

- Start in `scripts/` if you want to reproduce a workflow.
- Start in `src/electrodialysis_experiment/processes/` if you want to inspect
  the flowsheet implementation.
