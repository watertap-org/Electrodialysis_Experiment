Utilities Documentation
=======================

This section documents modules under
``src/electrodialysis_experiment/utils``.

These utilities provide reusable support for:

- model snapshot inspection,
- YAML-driven model value/scaling updates,
- solver option configuration,
- regression/statistical analysis, and
- common Plotly figure generation.
